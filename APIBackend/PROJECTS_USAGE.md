# Projects API Usage

Base URL: /projects

Fields used:
- id (uuid) - generated by database default
- name (varchar(120))
- project_key (varchar(20), unique)
- description (text, nullable)
- colour (varchar(30), nullable)
- created_at (timestamptz) - default now()

Required environment variables (see .env.example):
- SUPABASE_URL
- SUPABASE_ANON_KEY

Assumed Supabase tables:
- projects
  - id uuid primary key default gen_random_uuid()
  - name varchar(120) not null
  - project_key varchar(20) not null unique
  - description text null
  - created_at timestamptz not null default now()
  - colour varchar(30) null
- tasks (optional for counts)
  - id uuid primary key default gen_random_uuid()
  - project_id uuid not null references public.projects(id)
- bugs (optional for counts)
  - id uuid primary key default gen_random_uuid()
  - project_id uuid not null references public.projects(id)

Notes:
- For the /projects GET endpoint to return "tasks" and "bugs" counts, ensure the foreign key names in Supabase are:
  - tasks.project_id -> projects.id (constraint name: tasks_project_id_fkey)
  - bugs.project_id -> projects.id (constraint name: bugs_project_id_fkey)
- If your constraint names differ, update the select in src/api/projects.py accordingly:
  tasks:tasks!<your_tasks_fk_name>(count), bugs:bugs!<your_bugs_fk_name>(count)
- RLS: configure according to your needs. For public read/write during development, you can temporarily disable RLS or add permissive policies.

Endpoints:

GET /projects
- Response 200: Array of projects
- Example:
  [
    {
      "id":"uuid",
      "name":"My Project",
      "project_key":"APP",
      "description":"Desc",
      "colour":"#FF8800",
      "created_at":"2025-01-01T00:00:00Z"
    }
  ]

POST /projects
- Body (all fields accepted; created_at optional and if omitted Supabase uses now()):
  {
    "name": "New Project",
    "project_key": "APP",
    "description": "Optional",
    "colour": "#FF8800",
    "created_at": "2025-01-01T00:00:00Z"
  }
- Response 201:
  {
    "id":"uuid",
    "name":"New Project",
    "project_key":"APP",
    "description":"Optional",
    "colour":"#FF8800",
    "created_at":"2025-01-01T00:00:00Z"
  }

Troubleshooting:
- 500 Configuration error: Ensure SUPABASE_URL and SUPABASE_ANON_KEY are set in APIBackend/.env.
- 4xx from Supabase: Check table name, columns, and RLS policies in Supabase. The backend forwards Supabase error messages when possible.
